# Настройка синхронизации данных через GitHub

## Как это работает

1. **Data Gist** — хранит все данные сайта (`petochania-data.json`: котята, FAQ, отзывы и т.д.)
2. **Config Gist** — хранит актуальный ID Data Gist (обновляется автоматически при каждом сохранении)
3. **sync-config.json** в репозитории — сообщает всем устройствам, где искать Config Gist

Благодаря Config Gist синхронизация работает **даже с токеном только с правом `gist`** — не нужно каждый раз коммитить в репозиторий.

## Быстрая настройка (5 минут)

### Шаг 1: Создайте GitHub Personal Access Token

1. [GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)](https://github.com/settings/tokens)
2. **Generate new token (classic)**
3. Отметьте **`gist`** (обязательно)
4. Опционально **`repo`** — чтобы sync-config.json обновлялся в репозитории автоматически
5. Скопируйте токен (`ghp_...`)

### Шаг 2: Настройте в админ-панели

1. Откройте: `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПО/admin-panel-backend.html`
2. Войдите: `admin` / `admin123`
3. **Настройки → Синхронизация данных**
4. Вставьте токен
5. Нажмите **«Проверить соединение»** (опционально)
6. Нажмите **«Сохранить настройки синхронизации»** ← обязательно!

После сохранения вы увидите:
- **Data Gist ID** — где хранятся данные
- **Config Gist ID** — через который все устройства узнают актуальный Data Gist ID

### Шаг 3: Обновите sync-config.json (если нет права repo)

Если токен только с `gist`, скопируйте блок из админки и вставьте в файл `sync-config.json` в репозитории на GitHub:

```json
{
  "gistId": "ВАSH_DATA_GIST_ID",
  "configGistId": "ВАSH_CONFIG_GIST_ID",
  "lastUpdated": "2026-06-29T..."
}
```

Закоммитьте — через 1–2 минуты GitHub Pages подхватит изменения.

> Если добавили право **`repo`** к токену, этот шаг выполнится автоматически.

## Важно

- **Не редактируйте сайт через localhost** (`npm start`), если хотите видеть изменения на GitHub Pages — используйте админку на опубликованном сайте
- Токен хранится **только в браузере**, где вы его сохранили — это нормально, для записи нужен только один компьютер администратора
- **Все устройства читают** данные из одного Gist через Config Gist
- После настройки статус должен показывать: **GitHub Gist Sync ✅**

## Устранение проблем

| Проблема | Решение |
|----------|---------|
| Токен пропадает после F5 | Нажмите «Сохранить настройки», не только «Проверить». Должна появиться надпись «Токен сохранён» |
| Изменения только на одном устройстве | Настройте Gist sync, проверьте Config Gist ID в статусе |
| sync-config.json не обновился | Скопируйте JSON из админки и закоммитьте вручную, или добавьте право `repo` |
| Ошибка создания Gist | Проверьте право `gist` у токена |

## Безопасность

- Gist публичный — данные сайта (котята, тексты) доступны по ID, но ID сложно угадать
- Не публикуйте GitHub токен
- При компрометации — отзовите токен на GitHub и создайте новый
